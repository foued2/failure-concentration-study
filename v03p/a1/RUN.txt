A1 package - publication and validation procedure
=================================================

Branch: review/a1-package
Status: NOT FROZEN, NOT PHASE-AUTHORIZED. Published for independent review
(integrity pass + code-level review) only. Publication does not authorize
Phase 1 and does not change the RevF freeze.

Scope
-----
A1 = support-rule comparison (S0 vs S1(m) vs S2(m), m in {2,4,6}; B_min=8;
2 <= k <= 24). Deterministic exact enumeration, Python standard library only;
no sampling, no random, no Monte Carlo, no generation, no hidden-outcome access.
S2 is a candidate operationalization, NOT part of RevF: RevF never defines S2
or its strata. All outputs are SUPPORT-ONLY probabilities, not complete-rule or
full-study feasibility.

Interpreter
-----------
RevF (review/revf-package) pins CPython 3.14.0, standard library only. This is
satisfied by the repository .venv (pyvenv.cfg: version_info = 3.14.0). The
published outputs were reproduced byte-identically under BOTH the pinned
interpreter (repository .venv, CPython 3.14.0) and a system CPython 3.14.5, and
across repeated runs. NO interpreter deviation remains: out/a1_report.md and
out/a1_tables.json hashes are unchanged under both interpreters. The verifier
should still confirm the pinned .venv run reproduces the hashes below.

  - RevF regression: F_bl cells (a/b/c-hist at many N) and O4 cells match RevF

    E[bl-support] within 5e-2 relative.
  - Split sizes: 113->T=28, 150->T=38, 450->T=113, 600->T=150.
  - Final line: "FAILURES: none"; process exit code 0.
  - Determinism: out/a1_report.md and out/a1_tables.json are byte-identical on
    re-run (same machine, same interpreter).

Validation procedure for the verifier
-------------------------------------
  1. Confirm file scope: exactly the five files above; no __pycache__.
  2. Recompute SHA-256 and byte counts; compare to the table.
  3. Run under the pinned interpreter (<repo>/.venv/Scripts/python.exe,
     CPython 3.14.0) from v03p/a1/; expect exit 0 and "FAILURES: none"; compare
     out/a1_report.md and out/a1_tables.json bytes to the published hashes.
  4. Confirm run.log content equals the published UTF-8 log after EOL
     normalization (the preceding UTF-16LE original is documented above).

Carried caveats (from out/a1_report.md; not new claims)
------------------------------------------------------
  - N_b = fixed count of unique valid bodies; 113/450 are rho=0.25 plug-in
    proxies for expected unique counts; validity and duplicate losses are
    unmodeled. Fixed-unique-count is a genuine approximation; NO directional
    (optimistic) claim is established without the count distribution and the
    shape of p(n).
  - S2 middle-region mass is 0.357 at k=5 and 0.0 at k=10 and k=20, i.e. the
    middle can be empty; at k=20 the candidate strata are C=0.2 vs C=0.25.
    Thresholds are stated on attainable z; strata are reported in C. The
    z -> C mapping is defined in the module docstring.
  - Any "best" value requires a stated optimization domain (all enumerated
    rules vs the designated non-vacuous subset). At c-hist @ N=150: maximum over
    all rules is S1-m2 = 7.52e-4; S1-m4 = 3.76e-4. The RevF O4 cell at 3.8e-6 is
    a different reference and is not a substitute for either.
