# Controlled Python pipeline integration

This directory contains a software calibration only. It is not a solver-generation run and contributes no natural-solver observations. The host makes one input available per Sandbox session; the guest receives no suite file, oracle, labels, or authoritative records. Host code retains the 30-probe battery and 20-input evaluation bank, verifies each closed transport, and computes all correctness labels and features.

The four controlled bodies intentionally return a wrong answer on selected diagnostic input identities to validate family aggregation. They are not evidence about naturally generated solvers.
